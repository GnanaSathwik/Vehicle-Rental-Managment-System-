# Vehicle Rental Management System

Academic DBMS project focused on managing vehicle rentals, customers, bookings, billing, payments, maintenance, and employee records.

## Features
- ER Diagram Design
- Database Normalization (1NF, 2NF, 3NF)
- SQL Table Creation
- Queries using JOIN, GROUP BY, HAVING
- Stored Procedures
- Triggers
- User-defined Functions
- Transaction Control
- Access Control

## Technologies Used
- MySQL
- DBMS Concepts
- SQL
